# JSON Schemas for the tests

The tests use these copies, so they do not use the network.

| File | Source |
| --- | --- |
| `sarif-schema-2.1.0.json` | The SARIF 2.1.0 schema of OASIS (errata 01), from `oasis-tcs/sarif-spec`, file `sarif-2.1/schema/sarif-schema-2.1.0.json`. |
| `openapi-3.1-schema-2022-10-07.json` | The OpenAPI 3.1 schema of the OpenAPI Initiative, `https://spec.openapis.org/oas/3.1/schema/2022-10-07`. The copy comes from the package `openapi-spec-validator` 0.7.2, file `openapi_spec_validator/resources/schemas/v3.1/schema.json`. |
